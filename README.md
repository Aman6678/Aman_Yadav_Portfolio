
# Aman Yadav | Sustainability & ESG Portfolio

Welcome to my personal portfolio.

I am a Master in Management student at Audencia Business School, focusing on sustainability, ESG, decarbonisation, business strategy, data analysis, and automation.

This website showcases my professional experience, academic background, certifications, and technical skills.

## Portfolio Sections

- **About Me:** My background and professional interests.
- **What I Do:** Sustainability, ESG, data, and automation.
- **Journey & Experience:** Education and professional experience.
- **Certifications:** Professional certifications with full-size previews.
- **Skills & Toolkit:** Sustainability frameworks, environmental analysis, and digital tools.
- **Contact:** LinkedIn and email.

The Projects section is temporarily hidden and will be added when projects are ready.

## Technologies Used

The website is built using:

- React
- TypeScript
- Vite
- Three.js and React Three Fiber
- GSAP
- CSS

The homepage includes an animated 3D character. Other sections use responsive layouts, subtle animations, and lightweight interactions.

## Running Locally

1. Install dependencies:

   npm install

2. Start the development server:

   npm run dev

3. Open the local URL displayed in the terminal, usually http://localhost:5173/

## Production Build

To create the production version:

   npm run build

To preview the production build:

   npm run preview
